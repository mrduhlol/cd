# Agent instructions

## Sending files to a user

To send a local file with CD, follow
[`skills/cd-file-sharing/SKILL.md`](skills/cd-file-sharing/SKILL.md): run
`cdx send <file>` and reply with the link `https://cd.yash0.in/#<code>` built
from the code it prints.

## Agent skills

### Issue tracker

Issues and specs for this repo live as GitHub issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context layout with root `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.
